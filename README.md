The node class is used to create individual elements that stare data and a reference to the next node.

The linked list class is used to create a linked list and contains methods to append, display, and search for elements in the list.
The append() method adds a new node at the end of the list
The display() method prints the elements of the list
The search() method searches for a specific element in the list and returns True if the element is found and False if it is not found.

# Concept Questions
1. What is the role of a class in a linked list?
It's used as a blueprint to create nodes and linked lists which helps organize the code and define how the data structure works.

2. What is the difference between a node and a linked list?
a node is a single element that contains data and a reference to the next node while a linked list is a collection of connected nodes.

3. Why do we use None in next?
We use None to show that there is no next node as it marks the end of the linked list.
4. How is a linked list different from a python list?
A python list stores elements together in memory while a linked list stores elements in separate nodes connected by pointers.

5. Why is OOP useful for data structures?
OOP helps organize code into classes and makes it easier to manage, reuse, and understand complex data structures.
